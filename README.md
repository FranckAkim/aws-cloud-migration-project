# NovaTech Solutions — AWS Cloud Migration

## Company Overview

**NovaTech Solutions** is a fictional software company that provides inventory and order management software to small and medium-sized businesses. The company currently runs its application on three on-premises servers: one server hosts the web application, one runs the backend/API, and one stores the PostgreSQL database. The company is responsible for maintaining the hardware, networking, backups, security, and software on all three servers.

## Why migrate?

NovaTech Solutions wants to move to AWS because relying on three physical servers creates a lot of risk for the business. If one of the servers fails, part of the application could stop working until someone fixes or replaces it. If the company suddenly gets more customers and traffic, the existing servers may not have enough capacity to handle the demand. Managing backups and recovering from failures also takes time and requires employees with the right knowledge. Moving to AWS would give the company more flexibility to scale its infrastructure when needed and improve its ability to recover from failures. It would also reduce the amount of physical hardware the company has to maintain and allow the technical team to focus more on the application instead of managing servers.
